# Psychrometric Analysis Workbench

Moist-air property calculator for HVAC courses. Enter dry-bulb and dew-point temperatures and pressure to get the humidity properties of the air.

## Live tool

[Open Psychrometric Analysis Workbench](https://nuhaaljuneidi.github.io/sbed_humidity_calculator/)

## Features

- Relative humidity, absolute humidity, specific humidity, and wet-bulb temperature.
- Units in °C, °F, or K and Pa, kPa, or atm, with an option to show the formulas used.
- Moist-air composition view and HVAC context (ASHRAE Standard 55 comfort range).

## Run locally

Open `index.html` in a modern browser. No build step is needed.
